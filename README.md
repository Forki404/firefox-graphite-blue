# 🔷 Firefox Graphite Blue

A sleek, modern dark CSS theme for Mozilla Firefox featuring deep graphite shades and vibrant blue accents.

## 💡 Recommendation

For the best visual experience, please enable the default **Dark Mode** in Firefox settings (`about:addons` ➔ **Themes** ➔ **Dark**):

## ✨ Features

- **Graphite & Blue Palette**: Clean, distraction-free dark UI designed for low-light environments.
- **Modern Interface**: Refined tab bar, URL bar, and popup styling.
- **Lightweight**: Pure CSS (`userChrome.css` / `userContent.css`) with zero performance overhead.

---

## 🛠️ Installation

### Step 1: Enable Custom User Stylesheets
1. Open Firefox and type `about:config` in the address bar, then press **Enter**.
2. Accept the warning ("Accept the Risk and Continue").
3. Search for:
   ```text
